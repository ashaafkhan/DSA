# DSA — Concept Revision Solutions

C++ solutions to the **takeUforward (TUF+) "DSA Concept Revision"** problem set, organized in the exact order the problems appear in the course tracker (matching the screenshots this was built from). Each problem has its own folder containing a `solution.md` with the problem statement, the optimal C++ solution, the original problem link, and submission stats.

Click any problem name below to jump straight to its solution.

## Notes

- All solutions are written in **C++**.
- Each `solution.md` follows the same format: **Problem Description → Solution (code) → Problem Link → Stats**.
- The order above mirrors the topic-wise tracker sequence (Sorting & Arrays → Binary Search), so working top-to-bottom follows the intended learning path.
